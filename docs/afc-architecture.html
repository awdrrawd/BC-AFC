HeartLock

HeartLock 是 AFC bundle 內的功能模組，共用中央 I18N、Hook registry 與訊息入口。

核心

  • lock.js 鎖具套用與完整性
  • permissions.js 關係權限
  • storage.js 保存與對帳
  • net.js 遠端同步

互動

  • panel.js DOM 面板
  • tabs/ 總覽、筆記、計時、控制、解鎖
  • datepicker.js 日期選擇

運行功能

  • timer.js 到期解鎖
  • vibe.js 震動循環
  • hooks/orgasm.js 高潮模式
  • events.js 模組內事件

翻譯系統

AFC 與 HeartLock 共用一套引擎。HeartLock 使用 hl namespace，沒有第二份 I18N。
