# 遊戲內驗收清單

單元測試與 VM 測試無法涵蓋伺服器行為。以下項目需要**兩位載入同一版本的玩家**在實際 BC 伺服器驗收。完成後請直接從此清單刪除。

## 關係與同步
- [ ] 頂層 `Target` 的 Hidden 訊息只送達對象：申請 → 接受 → 升格 → 分手 → 恢復，全流程
- [ ] 一方修改戀人／鎖權限後，同房另一方不需查詢即可看到更新（依賴伺服器對 `OnlineSharedSettings` 的房內同步）
- [ ] 戀人進入／離開私人房後，`getLoverRoom()` 與房名分享正確更新
- [ ] Profile 面板 1–10／11–20 分頁與右向三角循環；與 FCM 等 priority 8 overlay 共存
- [ ] 與仍使用舊版 AFC 的對象互動：舊版握手被忽略；細節欄位空白、摘要正常
